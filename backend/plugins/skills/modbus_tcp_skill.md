# Modbus TCP 测试用例生成 Skill

为所有走 Modbus TCP 的设备生成用例——PLC、机械臂、电力/温控仪表、远程 IO 模块。
**同一套驱动，不按品牌区分。**

## 1. 命令生成规则

1. 每个测试步骤的 action 用**紧凑写法**或 **JSON 写法**，二选一：
   - 紧凑：`FC03:40001:2`、`FC06:40010:1`、`FC01:00001:8`、`FC05:00003:1`
   - JSON：`{"fc": 3, "addr": 100, "count": 2, "dtype": "float32"}`
2. 地址优先照抄设备手册的引用地址（`40001` / `30001` / `10001` / `00001`），驱动会自动换算。
3. 读 32 位及以上数据（float32 / int32）**必须显式写 `dtype`**。
4. `device_type` 填 `plc`，`devices_required` 包含 `modbus_tcp`。
5. **不要生成点位名或变量名**——本平台不做点位表，一律用裸地址。

## 2. 解析配置规则

响应是纯文本数值（如 `17000`、`23.5`、`1`）。解析配置一律：

```json
{"name": "温度", "data_type": "dec", "unit": "text", "start": 0, "length": 1,
 "conditions": {"min": 20, "max": 80}}
```

- 数值用 `data_type: "dec"`；开关量用 `data_type: "bool"`；文本用 `string`
- **单位必须是 `text`**（用 `byte` 会把 `1700` 这类响应误解析为十六进制字节）
- 范围判定写 `min` / `max`，枚举判定写 `equals`

## 3. 按设备类型的典型用例

### 3.1 PLC 数据交互

```
1. FC03:40001:1                      读保持寄存器 → 断言值域
2. FC06:40010:1                      写控制字 → 断言返回 OK
3. FC03:40010:1                      读回 → 断言等于 1（写后校验）
4. {"fc":3,"addr":40020,"count":2,"dtype":"float32"}   读工程量 → 断言值域
```

### 3.2 机械臂（Modbus TCP 做 IO / 寄存器协作）

三件事：下发点位或触发 → 等待到位信号 → 读状态与 IO。**不做插补/力控/示教。**

```
1. FC16:40010:1,100,200,300          下发目标坐标/点位号
2. FC05:00001:1                      置"启动"线圈
3. FC02:10001:1                      读"到位"离散输入 → 断言等于 1
   （未到位则用 loop 节点按 500ms 重试，最多 20 次后判失败）
4. FC03:40050:1                      读当前状态字 → 断言等于 3（运行中）
5. FC05:00002:1                      置"夹具夹紧"线圈
6. FC02:10002:1                      读"夹紧到位" → 断言等于 1
```

### 3.3 工业仪表（温控表 / 电力表）

```
1. FC04:30001:1                      读测量值（输入寄存器）
2. FC03:40001:1                      读设定值 → 断言等于目标
3. 多条采样后判定稳定性（范围 ≤ x）
```

## 4. 负向用例

| 场景 | 写法 | 期望 |
|------|------|------|
| 地址不存在 | `FC03:49999:1` | 返回 `ERROR: ILLEGAL_DATA_ADDRESS(0x02)`，连接保持 |
| 写入值越界 | `FC06:40001:99999` | 返回 `ERROR: ILLEGAL_DATA_VALUE(0x03)` |
| 从站离线 | 断开网线后读 | 抛连接错误，设备自动置离线 |

> 注意区分两类失败：**有应答的异常**（返回 ERROR 文本，可断言）与**无应答**（连接断开）。

## 5. 常见坑

- 读 float32 得到乱数 → 切换连接参数 `word_order`（big ↔ little）
- 线圈/离散量地址写成 `00001` 形式时不要写成 `0`
- 单次读取寄存器数超过 125 会被设备拒绝，需要分段读
- Modbus 不会主动上报，需要轮询时用 loop 节点或配置 `poll` 参数
